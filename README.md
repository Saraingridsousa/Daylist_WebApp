# Daylist WebApp

Este é um projeto [Next.js](https://nextjs.org/) criado com TypeScript e Tailwind CSS.

## Como começar

Primeiro, instale as dependências:

```bash
npm install
# ou
yarn install
# ou
pnpm install
```

Depois, execute o servidor de desenvolvimento:

```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
```
